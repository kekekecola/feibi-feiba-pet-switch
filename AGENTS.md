# Installing or importing this project

For a request to install/upgrade this project, read README.md first. Do not import every image or every release as a new pet.

The only pet sprite sheets are `pets/feibi-jiubi/spritesheet.png` and `pets/feiba-jiubi/spritesheet.png` (1536×1872, v1). The CG strip in app/assets, tray ICO and media GIFs are application resources, not additional pets. Never upload those as pets.

When using a Pets connector, list the user's existing pets before creating any cloud copy. Reuse the resolved existing pair. Duplicate names require the user to identify which stable IDs to keep; do not delete cloud records automatically. Upgrade the application separately from the pet library. Do not repeatedly create/import the pair while waiting for images to load.

If a pet is listed but its image is blank or flickers, stop repeated import/switch attempts. Capture the client version and actual diagnostic/error text. A successful selection or visible window alone does not prove the image rendered. Package validation cannot establish that another user's network can load cloud sprite URLs.
