# 验证范围

发布前在维护者当前 Windows 桌面、客户端包版本 26.1106.6628.0 上验证。不是全新电脑或全部版本认证。

| 验证 | 结果与边界 |
| --- | --- |
| 两个原生宠物双向切换 | 通过；结束时原生可见、CG 隐藏，保留原形态和大小。 |
| 自定义大小 | 实测设置158、DPI168时两种形态的原生单格宽均278物理像素，CG宽417。不是任意 DPI / 多屏组合穷举测试。 |
| 普通切换焦点 | 临时输入窗口中双向切换，每5毫秒采样，焦点始终留在该窗口。另测主客户端页面保持。 |
| 阻塞故障 | 在真正 MSAA 选择调用位置替换为120秒等待；在CG已显示、原生已隐藏后，测试控制器以5秒超时结束工作进程，约5.4秒完成撤CG和恢复原生。模拟的是提供程序不返回，不是证明所有真实COM故障类型均已覆盖。正式切换超时22秒。 |
| 辅助窗口重连 | 关闭本工具拥有的后台设置窗口，等待重建；排队切换完成，回到原始形态，大小158未改变。没有在本次发布验证中关闭整个聊天客户端。 |
| 名称和ID变化 | 对真实界面使用临时过期名称 / ID 配置，完整描述找回角色按钮，原生图像名称确认当前ID。另以合成缓存测试同图重新导入与歧义拒绝。没有实际删除并重建云端宠物。 |
| 菜单语言 | 当前语言包按四个语义键提取到59、62、59、63个不同标签；实际界面操作以当前中文环境测试，未逐语言点击测试。 |
| 请求协议 | 无效输入、超大时间戳、过期请求、取消 / 开始竞争有针对性验证。 |
| 进程异常退出 | 已在实际CG期间结束测试工作进程，验证看门狗和恢复记录；未模拟断电或所有相关进程同时退出。 |
| 新用户安装 | 发布包资源校验、安装计划预览、任务XML、临时目录宠物安装 / 备份、源码测试通过。尝试在新虚拟环境从PyPI安装依赖时遇到本机TLS连接失败，未完成全新依赖下载验证；代码测试使用已有依赖环境通过。未在另一台全新电脑完整安装，登录计划任务受系统策略限制时可能需手动处理。 |

Windows CI 仅验证可自动运行的代码与资源检查。不能用绿色 CI 状态推断真实客户端集成全部通过。
