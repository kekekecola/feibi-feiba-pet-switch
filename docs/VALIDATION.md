# 验证范围

发布前在维护者当前 Windows 桌面、客户端包版本 26.1106.6628.0 上验证。不是全新电脑或全部版本认证。

| 验证 | 结果与边界 |
| --- | --- |
| 两个原生宠物双向切换 | 通过；结束时原生可见、CG 隐藏，保留原形态和大小。 |
| 自定义大小 | 实测设置158、DPI168时两种形态的原生单格宽均278物理像素，CG宽417。不是任意 DPI / 多屏组合穷举测试。 |
| 普通切换焦点 | 临时输入窗口中双向切换，每5毫秒采样，焦点始终留在该窗口。另测主客户端页面保持。 |
| 阻塞故障 | 在真正 MSAA 选择调用位置替换为120秒等待；在CG已显示、原生已隐藏后，测试控制器以5秒超时结束工作进程，约5.4秒完成撤CG和恢复原生。模拟的是提供程序不返回，不是证明所有真实COM故障类型均已覆盖。正式切换超时22秒。 |
| 辅助窗口重连 | 关闭本工具拥有的后台设置窗口，等待重建；排队切换完成，回到原始形态，大小158未改变。没有在本次发布验证中关闭整个聊天客户端。 |
| 名称和ID变化 | 对真实界面使用临时过期名称 / ID 配置，完整描述找回角色按钮，原生图像名称确认当前ID。另以合成缓存测试同图重新导入与歧义拒绝。没有实际删除并重建云端宠物。 |
| 菜单语言 | 当前语言包按四个语义键提取到59、62、59、63个不同标签；实际界面操作以当前中文环境测试，未逐语言点击测试。 |
| 请求协议 | 无效输入、超大时间戳、过期请求、取消 / 开始竞争有针对性验证。 |
| 进程异常退出 | 已在实际CG期间结束测试工作进程，验证看门狗和恢复记录；未模拟断电或所有相关进程同时退出。 |
| 新用户安装 | 发布包资源校验、安装计划预览、任务XML、临时目录宠物安装 / 备份通过。本机pip直连PyPI遇到TLS连接失败，随后从官方PyPI下载wheel并核对其公布的SHA-256，在全新虚拟环境中安装三个依赖成功，全部六项测试及运行模块导入通过。未在另一台全新电脑完整安装，登录计划任务受系统策略限制时可能需手动处理。 |

Windows CI 仅验证可自动运行的代码与资源检查。不能用绿色 CI 状态推断真实客户端集成全部通过。

## v1.1.0 增补

自动化测试共12项：原有6项之外，加入复制/配置/任务注册/任务启动四种失败注入，验证旧宠物、映射及任务恢复；新增文件回滚；素材缺失、运行控制退出超时和重复卸载；过期记录清理对活动、待处理、近期记录和恢复日志的保护；主日志轮转及工作日志分离。文件变化在临时目录实测，调度器修改采用mock；另只读验证实际Windows任务查询接口。尚未在另一台全新电脑完整安装。

维护改动同时加载到本机F8服务，实际双向原生切换通过：设置158、DPI168时原生单格宽278、CG宽417，结束时保留原始形态和大小，原生可见且CG隐藏。

## v1.2.0 增补

自动化测试共29项，新增快捷键格式、注册冲突保留原绑定、先注册后释放旧绑定、坏配置修复备份、诊断字段筛选、更新摘要与压缩包路径验证、防降级、联网失败保持旧指针、准备完成后才激活、健康检查失败回退、更新互斥、恢复中断激活、独立上次可用按键和30分钟调度检查。

本机实测版本化安装和两个计划任务注册成功，托盘Shell_NotifyIcon注册成功；在线改绑到Ctrl+Alt+H，外部占用Ctrl+Alt+J时保留H，测试后恢复F8。诊断读回心跳、进程与托盘状态正常。旧版两次总耗时4009.9/4086.4ms，新版3659.5/3334.9ms；新版工作进程内首次CG显示为827.4/712.3ms，未计外部启动开销。样本很小，不能推广为全部电脑的性能结论。两次切换结束后仍为原形态、大小158；单格278物理像素与CG417一致。

首次安装/重连的焦点限制仍适用。故障回退测试使用临时目录与模拟调度器，不能等同真实断电恢复；未在全新电脑、所有显示缩放或所有快捷键组合逐一验证。

## v1.2.1 增补

新增依赖清单CRLF/LF等价测试，总计30项。本机下载公开发行包、校验与暂存已实测；首次完整流程在准备依赖阶段发现仅换行差异会触发多余重装，本机pip失败后旧服务保持运行。补丁修正该判断，不跳过依赖导入检查。
